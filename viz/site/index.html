enharmonic

Real-time enharmonic pitch spelling for MIDI.

A written score names each note with a letter and an accidental. A MIDI stream keeps only the twelve pitch classes and throws that away: it cannot say whether note 61 is a C♯ or a D♭. The letter is not cosmetic — it tells a reader the note's harmonic identity. This library recovers it from musical context alone.

The idea

A spelling can be wrong in two independent ways. The first is coherence: inside an F‑minor chord, note 68 is A♭, not G♯, because G♯ would make an augmented second where the ear hears a minor third. The second is the comma, or side: a passage in C♯ major written in D♭ major is the same pitches one turn around the spiral of fifths — a coherent transposition, not an error.

The speller settles both from a few simple principles in one harmonic space, with no key detection anywhere: a running seven-letter scale, an interval score that rewards consonance, and a spiral that decides which side of the comma a passage sits on. The side it lands on is just a statistic of the notes it has already committed.

Two spellers

One engine, run at the latency you have. Real time spells each note as it plays, from past context only. Two-pass reads the whole piece forward and backward and reconciles the two, fixing the modulation boundaries the streaming pass spells late.
